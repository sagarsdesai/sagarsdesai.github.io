An evolving framework that puts LLM agents to work on real software development tasks — code generation, debugging, refactoring, and more.

![Agent LLM Dev demo](llm_agents_15sec.gif)

## What it does

- Autonomous task planning and execution over a codebase
- Multi-step reasoning with tool use (file read/write, bash execution, search)
- Human-in-the-loop checkpoints for high-risk operations
- Planned: multi-agent coordination, long/short-term memory, self-reflection

## Stack

Python · OpenAI/Anthropic API · Custom agent loop
